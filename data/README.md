# Dataset

`orders.csv` is a **synthetic demo dataset** created for learning and testing this project. It is not presented as real company sales data.

## Schema

| Column | Meaning |
|---|---|
| Order ID | Unique order identifier |
| Order Date | Date of the order |
| Product | Product name |
| Category | Product category |
| Quantity | Units purchased |
| Price | Unit selling price |
| Discount | Discount percentage |
| Region | Customer region |

For a stronger portfolio case study, replace the demo file with a real, appropriately licensed public dataset and document its source here.
